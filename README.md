# نظام متابعة الصيدليات ومخازن الأدوية — Phases 01–12

هذا المشروع يضم تأسيس Flutter في المرحلة 01، ووحدة إدارة المنشآت في المرحلة 02، ووحدة السداد والغرامات في المرحلة 03، والإجراءات والمتابعة في المرحلة 04، والمرفقات في المرحلة 05، والبحث والفلترة في المرحلة 06، والاتصالات والرسائل في المرحلة 07، ولوحة الإحصائيات والمؤشرات في المرحلة 08، ومحرك التقارير الداخلي في المرحلة 09، وتصدير PDF وExcel في المرحلة 10، والحقول المخصصة الديناميكية في المرحلة 11، ثم النسخ الاحتياطي والاستعادة في المرحلة 12 باستخدام Riverpod وIsar وClean Architecture.

تدعم وحدة المنشآت الإضافة والتعديل والحذف والعرض والبحث السريع والحفظ والاسترجاع المحلي، مع منع تكرار الرقم التسلسلي والتحقق من الحقول الإلزامية وتواريخ الترخيص. راجع [ملخص المرحلة 02](PHASE-02-SUMMARY.md).

لم تُنفذ الاختبارات النهائية والإطلاق الرسمي خارج نطاق المرحلة 12.

## ملاحظة بيئة البناء

تم إنشاء المصدر على بيئة ARM64 لا تتوفر لها حزمة Flutter Linux رسمية؛ لذلك لم يُنفّذ build داخل هذه البيئة. شغّل الأوامر التالية على جهاز Flutter x64 أو CI مناسب:

```bash
flutter pub get
flutter pub run build_runner build --delete-conflicting-outputs
flutter analyze
flutter test
flutter build apk
flutter build windows
```
